# Perceptron Exercise (Insper ANN/DL 2026.2)

Report / GitHub Pages site: see the `docs/` folder, published at
**https://stefanolinden.github.io/perceptron-exercise/**

## Contents

- `perceptron.py` — single script with the Perceptron implementation
  (from scratch, NumPy only), data generation for both exercises,
  training (plain and pocket), and figure generation.
- `docs/index.md` — the full report (approach, code, figures, analysis,
  results table) rendered as the GitHub Pages site.
- `docs/figures/` — the 6 required figures (PNG), generated by
  `perceptron.py`.
- `docs/results_table.md` — the results summary table.

## Reproducing

```bash
pip install numpy matplotlib
python3 perceptron.py
```

Uses a fixed seed (`np.random.default_rng(42)`) everywhere, so results and
figures are identical on every run.
